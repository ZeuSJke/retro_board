# Ошибка: Делегирование агентам

## Проблема

При реализации фичи "Автогенерация названия Action Item" я сделал всё сам вместо того чтобы делегировать агентам.

### Что я сделал:
- Сам написал код в `app/ai/ai_client.py`
- Сам добавил endpoint в `action_items.py`
- Сам обновил `BoardPage.tsx`
- Сам проверил тесты

### Что должен был сделать:
- Вызвать `@architect` для проектирования
- Вызвать `@backend-dev` для реализации бэкенда
- Вызвать `@frontend-dev` для реализации фронтенда
- Вызвать `@qa` для тестирования

## Почему это важно

1. **Агенты — специалисты** — у каждого своя роль и экспертиза
2. **Консистентность** — агенты следуют стандартам проекта из AGENTS.md
3. **Разделение ответственности** — каждый делает свою часть
4. **Обучение** — агент запоминает паттерны в свой memory

## Как избежать этой ошибки

### Правило:
**Никогда не пиши код сам, если есть соответствующий агент.**

### Алгоритм:
1. Получил задачу
2. Определил кто должен делать (@architect, @backend-dev, etc.)
3. Вызвал агента с задачей
4. Агент сделал работу
5. Проверил результат

### Исключения:
- Мелкие правки (исправление опечаток, форматирование)
- Исследование кода (@explainer)
- Срочные hotfixes (но потом записать в memory)
