# Ошибка: Делегирование агентам

## Проблема

При реализации фичи "Автогенерация названия Action Item" я сделал всё сам вместо того чтобы делегировать агентам.

### Что я сделал не так:
- Написал код сам (ai_client.py, endpoint, BoardPage.tsx)
- Не вызвал ни одного агента для реализации

### Что должен был сделать:
1. Вызвать `@architect` — спроектировать AI модуль
2. Вызвать `@backend-dev` — реализовать бэкенд
3. Вызвать `@frontend-dev` — реализовать фронтенд
4. Вызвать `@qa` — написать тесты

## Правило

**Для реализации фич — всегда используй агентов.**

### Когда использовать агентов:

| Задача | Агент |
|--------|-------|
| Новая сущность в БД | @architect → @backend-dev |
| Новый эндпоинт | @backend-dev |
| Новый UI компонент | @frontend-dev |
| Тесты | @qa |
| Рефакторинг | @refactorer |
| Аудит безопасности | @security |
| Документация | @docs |
| Анализ кода | @explainer |

### Когда НЕ использовать агентов:
- Мелкие правки (1-2 строки)
- Исследование/поиск
- Срочные hotfixes
